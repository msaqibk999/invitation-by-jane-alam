
Requires node 22 and above

## Run
```bash
npm install
npm run dev
```

## Assets
Copy these source assets into `public/`:
- `public/videos/rose-gold-blush.mp4`
- `public/music/track3.mp3`
- `public/images/slide-1.jpg` through `slide-4.jpg`

The original image URLs in the supplied HTML were generated asset URLs, so this version uses clean `/images/...` paths.

## Components
- `Hero.tsx`
- `Welcome.tsx`
- `InvitationCard.tsx`
- `Gallery.tsx`
- `Countdown.tsx`
- `InfoSections.tsx`
- `RSVP.tsx`
- `Controls.tsx`
- `Closing.tsx`
